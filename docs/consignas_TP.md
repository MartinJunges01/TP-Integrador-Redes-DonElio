# Consignas y Requerimientos - TP Integrador Redes (Don Elio)

## 1. Estructura General y Formato
- **Formato:** Documento PDF.
- **Estilo:** Fuente Arial 11, texto justificado, interlineado 1.5, márgenes de 2.5 cm.
- **Citas:** Formato APA 7ma edición para bibliografía.
- **Estructura del documento:**
  1. Introducción
  2. Desarrollo por partes
  3. Escenario de implementación
  4. Conclusión
  5. Bibliografía
  6. Anexos (códigos, diagramas, mockups, etc.)

## 2. Parte 1: Configuración de la Red e Infraestructura
- **1.1 Diseño y Topología:**
  - Elección y justificación de topología (ej. estrella, malla).
  - Escenario cliente pequeño (infraestructura acotada).
  - Escenario empresa grande (escalabilidad, segmentación).
  - **Diagrama de red** visual (draw.io, etc.).
  - Plan de direccionamiento IP (tabla con IPs, máscaras, gateways y funciones).
- **1.2 Configuración del Servidor:**
  - Sistema operativo (elección y justificación).
  - Servidor web o entorno de ejecución.
  - Base de datos (gestor y justificación).
  - Variables de entorno/configuración.
  - Seguridad básica.
  - Diseño de datos (tabla/entidad representativa de la BD).
- **1.3 Pruebas de Conectividad:**
  - Simulación de comandos `ping` y `traceroute`.
  - Prueba de servicio web.
  - Prueba de base de datos.
  - Prueba multiusuario (concurrencia).

## 3. Parte 2: Desarrollo de la Aplicación
- **Arquitectura y Stack:**
  - Tecnologías utilizadas con justificación.
  - Arquitectura del sistema (monolítico, cliente-servidor, MVC, etc.).
  - Módulos principales y sus responsabilidades.
  - Usuarios y permisos.
- **Diseño UI/UX:**
  - Bocetos, wireframes o capturas de las vistas principales (Dashboard, listados, formularios).
- **Lógica de la Aplicación:**
  - Pseudocódigo de funcionalidades principales.
  - Uso de librerías o frameworks clave.
  - Parámetros y retornos de funciones importantes.
  - Manejo de errores y validaciones.

## 4. Aspectos Transversales
- **Instalación:** Pasos en cliente pequeño.
- **Implementación (Empresa grande):** Adaptaciones para soportar volumen.
- **Escalabilidad:** Cómo puede crecer el sistema.
- **Backups y recuperación:** Estrategia ante fallas.
- **Mantenimiento:** Actualizaciones, reporte de errores.
- **Seguridad:** Autenticación, protección de datos, buenas prácticas.
